## Basics

| Item | Value |
| --- | --- |
| API base URL | `https://ownapi.dev/v1` |
| Auth | `Authorization: Bearer <your API key>` |
| Format | HTTPS REST + JSON; Chat/Completions follow the OpenAI API shape |

### cURL (non-streaming)

```bash
curl https://ownapi.dev/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

### List models

```bash
curl https://ownapi.dev/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Replace `YOUR_API_KEY` with your token. Use model IDs from `/v1/models`.
