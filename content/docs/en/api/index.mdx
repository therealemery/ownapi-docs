## Calling the API

All AI model endpoints use **https://ownapi.dev/v1** with **Bearer** authentication:

```http
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

Create keys in the [ownapi.dev](https://ownapi.dev) console. Paths below are relative to the base URL (e.g. Chat is `POST /v1/chat/completions`).

<Callout title="Note">
  Interactive pages on this site use the configured gateway URL; use `https://ownapi.dev/v1` in your own clients.
</Callout>
