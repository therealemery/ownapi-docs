## 调用说明

所有 AI 模型接口均通过 **https://ownapi.dev/v1** 访问，使用 **Bearer Token** 鉴权：

```http
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

在 [ownapi.dev](https://ownapi.dev) 控制台创建 API 密钥。下列路径均相对于 Base URL（例如 Chat 为 `POST /v1/chat/completions`）。

<Callout title="提示">
  下方页面中的「Try it」会使用本站点配置的网关地址；示例请求请以 `https://ownapi.dev/v1` 为准。
</Callout>
