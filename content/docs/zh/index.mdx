## 基础信息

| 项目 | 值 |
| --- | --- |
| API Base URL | `https://ownapi.dev/v1` |
| 鉴权 | `Authorization: Bearer <你的 API 密钥>` |
| 协议 | HTTPS，REST + JSON；Chat/Completions 兼容 OpenAI API |

### cURL 示例（非流式）

```bash
curl https://ownapi.dev/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

### 列出模型

```bash
curl https://ownapi.dev/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"
```

将 `YOUR_API_KEY` 替换为控制台中的令牌。模型 ID 以 `/v1/models` 返回为准。
