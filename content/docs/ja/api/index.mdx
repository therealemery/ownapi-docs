## API の呼び出し

AI モデル系エンドポイントは **https://ownapi.dev/v1**、**Bearer** 認証を使用します。

```http
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

キーは [ownapi.dev](https://ownapi.dev) コンソールで作成します。以下のパスは Base URL からの相対パスです（Chat は `POST /v1/chat/completions`）。

<Callout title="メモ">
  本サイトの Try it は設定済みゲートウェイ URL を使います。実装では `https://ownapi.dev/v1` を指定してください。
</Callout>
