## 基本情報

| 項目 | 値 |
| --- | --- |
| API Base URL | `https://ownapi.dev/v1` |
| 認証 | `Authorization: Bearer <API キー>` |
| 形式 | HTTPS REST + JSON（Chat / Completions は OpenAI API 互換） |

### cURL（非ストリーム）

```bash
curl https://ownapi.dev/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [{"role": "user", "content": "Hello"}]
  }'
```

### モデル一覧

```bash
curl https://ownapi.dev/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"
```

`YOUR_API_KEY` はコンソールのトークンに置き換えてください。モデル ID は `/v1/models` のレスポンスに従います。
